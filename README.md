# אסיפת הורים

מערכת לניהול אסיפות הורים למוסדות (חיידרים / תלמודי תורה). בשלב זה: אתר ניהול. הקו הטלפוני ייבנה בהמשך.

- אתר: `https://smti.uk/asifa/`
- Cloudflare Worker `asifa` + D1 `asifa`. כל דחיפה ל-`main` מתפרסת אוטומטית.

## מבנה

```
worker.js          נקודת כניסה: אתר + API
http.js            תגובות JSON אחידות ושגיאות
auth.js            כניסה (שם משתמש + סיסמה, או IP מורשה), טוקנים
admin.js           ניהול-על: מוסדות והרשאות כניסה
tenant_schema.js   הטבלאות הפרטיות של כל מוסד
classes.js         כיתות ומלמדים
students.js        תלמידים, טלפונים, ייבוא
meetings.js        אסיפות והגדרות כיתות
dashboard.js       לוח בקרה
migrate.js         טבלאות המערכת המשותפות (migrations/)
time.js            זמן ישראל
client/            האתר (index.html, styles.css, login.css, mobile.css, client-*.js)
```

## מסד הנתונים

טבלאות משותפות (בלבד): `tenants`, `access_rules`, `sessions`, `login_log`, `schema_migrations`.

לכל מוסד טבלאות משלו שמתחילות במזהה שלו, ונוצרות אוטומטית בהוספת המוסד:

```
t{id}_classes          כיתות + שם מלמד
t{id}_students         שם פרטי, משפחה, כיתה, ת.ז (לא חובה), שם האב
t{id}_student_phones   טלפון + תיאור (אב / אם / בית ...)
t{id}_meetings         אסיפה: שם, תאריך, אורכי פגישה לבחירה
t{id}_meeting_classes  לכל כיתה באסיפה: שעות ואורכי פגישה מותרים
```

מחיקת מוסד מוחקת את כל הטבלאות שלו. שינוי מבנה: גרסה חדשה ב-`tenant_schema.js` — כל מוסד מתעדכן אוטומטית.

## הרשאות

מנהל-על מוסיף מוסד (שם + פעיל), ובתוכו משתמשים (שם משתמש + סיסמה) או כתובות IP מורשות (כניסה אוטומטית).
כל הרשאה שייכת למוסד אחד בלבד. הרשאה בלי מוסד = מנהל-על.
