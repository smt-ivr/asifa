# אסיפה — מערכת קביעת תורים לאסיפות הורים

מערכת למוסדות (חיידרים / תלמודי תורה): פותחים אסיפה עם שעות לכל כיתה, ההורים קובעים תור בטלפון (ימות המשיח), והמזכירות והמלמדים מנהלים הכול באתר.

- אתר: `https://smti.uk/asifa/`
- שלוחת ימות: `https://smti.uk/asifa/api/yemot?tenant=<מזהה מוסד>`
- Cloudflare Worker `asifa` + D1 `asifa`. כל דחיפה ל-`main` מתפרסת אוטומטית (Workers Builds).

## מבנה

```
worker.js            נקודת כניסה: אתר, API, קו טלפוני, Cron
http.js              תגובות JSON אחידות ושגיאות
auth.js              כניסה, סיסמאות (PBKDF2), הרשאות (super / admin / teacher)
migrate.js           עדכון מבנה המסד אוטומטית (migrations/*.sql)
tenants.js           מוסדות (מנהל-על)
settings.js          הגדרות מוסד
users.js             משתמשי מוסד
classes.js           כיתות ומלמדים
students.js          תלמידים, טלפוני הורים, ייבוא
meetings.js          אסיפות, שעות לכיתות, פתיחה/נעילה, לוח, דוחות
bookings.js          מנוע התורים (שעות פנויות, קביעה, שיבוץ אוטומטי)
tzintuk.js           צינתוקים דרך ה-API של ימות
yemot_parents.js     הקו הטלפוני להורים
scheduled.js         נעילה אוטומטית, צינתוק "לא קבעו", תזכורות
time.js / phones.js  זמן ישראל, הקראת שעות ותאריכים, נרמול טלפונים
migrations/          מבנה המסד
client/              אתר הניהול (index.html, styles.css, print.css, client-*.js)
```

## ריבוי מוסדות

מסד אחד; בכל טבלה של מוסד יש `tenant_id`. המוסד מזוהה:
- באתר — לפי המשתמש שנכנס (מנהל-על בוחר מוסד, נשלח בכותרת `X-Tenant`).
- בטלפון — לפי `tenant` בכתובת השלוחה, או לפי המספר שחויג (`ApiDID`) שמוגדר למוסד.

## הקו הטלפוני

ההורה מזוהה לפי המספר המזוהה → כל הילדים שהמספר רשום אצלם. מספר לא מוכר מקיש קוד תלמיד ונשאל אם לשמור את המספר.

תפריט: 1 קביעה/שינוי · 2 שמיעת התורים · 3 לא נוכל להגיע (המלמד יחזור) · 4 ביטול · 5 הוספת ילד לפי קוד · 9 סיום (הקראת כל התורים).
בקביעה: בחירת ילד → 5/10 דקות → הצעת השעה המומלצת (ליד תורי האחים) → 1 אישור, 2 שעה אחרת, 3 הקשת שעה (1930), 0 חזרה.
כשההרשמה נעולה: שמיעה ו"לא נוכל להגיע" בלבד.

## כללי התורים

- שעות כל כיתה מחולקות לפרקים של 5 דקות; תור של 10 דקות תופס שניים. הפסקות חסומות.
- כל פרק תפוס נרשם ב-`booking_slots` עם מפתח ייחודי — שני הורים לא יכולים לקבל אותה שעה גם בלחיצה בו-זמנית.
- להורה עם כמה ילדים לא ייקבעו תורים חופפים (בתוספת "מרווח בין אחים" לפי הגדרת האסיפה).
